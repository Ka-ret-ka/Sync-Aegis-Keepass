# Sync-Aegis-Keepass
Этот скрипт пригодится тем, кто использует KeePass в качестве менеджера паролей (на linux и на android) и Aegis в качестве 2FA.

### Возможности:
1. Копирование всех бэкапов Aegis с android.
2. Синхронизация баз KeePass и создание бэкапа.
3. Архивирование бэкапов с проверкой пароля по значению-канарейке.

Для работы программы требуются зависимости:
```apt install adb keepassxc 7zip```
